# Güvenli Haberleşme Projesi

Kriptoloji dersi grup projesi. Sunucu – istemci – istemci mimarisinde güvensiz ve güvenli (AES-128) modda haberleşme. AES anahtarı; RSA-2048, Diffie-Hellman (2048 bit), ECC (ECDH) ve Kyber (ML-KEM-768) yöntemlerinden biriyle paylaşılır. Kullanıcı klavyeden metin ya da klasörden PDF dosyası gönderebilir.
